# FreshBite - Online Food Ordering

A modern, responsive food ordering web application built for the Free Web Development Internship Online by Data Alcott Systems[cite: 1].

- Student Code: DAS-EC-001[cite: 1]

- Task Link: https://www.freeinternships.in/blog/[cite: 1]

---

## Features
- Dynamic Food Menu: Renders food items dynamically using JavaScript arrays[cite: 1].
- Dietary Filtering: Filter dishes between All, Veg, Non-Veg, and Vegan[cite: 1].
- Interactive Shopping Cart: Real-time quantity adjustment, item removal, and subtotal calculation[cite: 1].
- Coupon & Discount Engine: Instant price deduction with coupon codes[cite: 1].
- Wishlist Management: Save favorite dishes for quick access[cite: 1].
- Simulated Checkout & Payment: Collects delivery details, payment gateway modal simulation, and live order tracking progress[cite: 1].
- Responsive UI: Clean design styled with warm food-themed colors, optimized for desktop and mobile devices[cite: 1].
- Zero Database Dependency: Pure frontend state management using Vanilla JavaScript[cite: 1].

## How to Run Locally
1. Clone the repository:
   git clone https://github.com/idfwamit/freshbite-food-ordering.git
2. Navigate into the folder:
   cd freshbite-food-ordering
3. Open index.html in any web browser.
