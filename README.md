A modern, responsive food ordering web application built for the Free Web Development Internship Online by Data Alcott Systems.

---

## Features
- Dynamic Food Menu: Renders food items dynamically using JavaScript arrays.
- Dietary Filtering: Filter dishes between All, Veg, Non-Veg, and Vegan.
- Interactive Shopping Cart: Real-time quantity adjustment, item removal, and subtotal calculation.
- Coupon & Discount Engine: Instant price deduction with coupon codes.
- Wishlist Management: Save favorite dishes for quick access.
- Simulated Checkout & Payment: Collects delivery details, payment gateway modal simulation, and live order tracking progress.
- Responsive UI: Clean design styled with warm food-themed colors, optimized for desktop and mobile devices.
- Zero Database Dependency: Pure frontend state management using Vanilla JavaScript.

---

## Built With
- HTML5: Semantic structure and layout
- CSS3: Custom styles, CSS Grid, Flexbox, and media queries
- JavaScript (ES6): DOM manipulation, state handling, and interactive cart logic
